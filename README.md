A program that writes one satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. The senator spent nine months writing the AI Safety Act — then emailed the final draft to his staff as a Pages file and asked them to turn it into one of those PDFs the kids use.

## Run it

```sh
node main.ts
```

This writes the one-liner to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The output is fixed and deterministic: 226 characters, one sentence, well inside the 320-character gate. Requires Node 22.18 or later; no dependencies to install.
